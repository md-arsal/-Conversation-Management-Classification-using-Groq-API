# Groq Conversation Summarizer & JSON Extractor

 Project Overview
This project demonstrates:
- Conversation history management with summarization.
- JSON schema-based information extraction using Groq API (OpenAI-compatible).

Assignment tasks implemented:
1. Conversation history with truncation.
2. Summarization after every *k*-th run.
3. JSON schema extraction (name, email, phone, location, age).
4. Demonstrations with multiple chat samples.
